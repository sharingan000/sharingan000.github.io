# Danil Karpov

Personal website and general CV, published at https://sharingan000.github.io/ using GitHub Pages.

The site uses plain HTML and CSS, with no build step. GitHub Pages serves the root of the `main` branch. `CV.pdf` is a copy of the general CV, not an application-specific version.

## Update the CV

Replace `CV.pdf` with the latest general CV, commit the change and push to `main`. Keep the filename unchanged so existing download links continue to work.

## Preview locally

Run `python3 -m http.server 8765` in this directory and open http://localhost:8765/.
